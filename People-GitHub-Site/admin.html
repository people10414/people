GitHub 재배포

편집 → 미리보기 확인 → ZIP 다운로드 → 압축 해제 → GitHub 파일 교체. ZIP 파일 자체가 아닌 압축을 푼 파일들을 올려 주세요.

GitHub에서 배포·수정하는 방법
  1. 배포 ZIP을 내보낸 뒤 압축을 풉니다.
  2. 내용물을 GitHub 저장소의 최상위에 올립니다.
  3. Settings → Pages → Deploy from a branch에서 main / (root)를 선택합니다.
  4. 배포 후 주소 끝에 /admin.html을 붙이면 이 편집기를 다시 사용할 수 있습니다.
  5. 재배포할 때도 ZIP 전체를 내보내 기존 파일을 교체하고 커밋합니다. 이 방식은 디자인과 기본 데이터까지 함께 갱신합니다.
  6. 다른 기기에서 이어서 편집하려면 JSON을 내려받아 보관하고, 이 화면의 JSON 불러오기를 사용하세요.

이 편집기는 브라우저 안에서만 작업합니다. 로그인이나 저장소 쓰기 권한을 갖지 않으며, 방문자가 공개 사이트 내용을 변경할 수 없습니다. 기기를 바꾸기 전에는 파일을 내려받아 주세요.
